# 🌿 My Life V2

My Life V2 is a personal life coach web application.

It helps you manage:

- 💪 Fitness
- 🥗 Nutrition
- ❤️ Health
- 🎯 Productivity
- 🔥 Habits
- 🤖 Smart Coach


## Features

### 🏠 Dashboard

- Daily overview
- Life Score
- Daily missions
- Progress tracking


### 💪 Training

- Workout categories
- Exercise library
- Sets and repetitions
- Workout tracking
- Muscle targeting


### 🥗 Nutrition

Enter what you eat:

Example:

"3 eggs chicken rice"

The app calculates:

- Calories
- Protein
- Carbs
- Fats


### ❤️ Health

Track:

- Weight
- Water
- Sleep
- Steps


### 🎯 Productivity

Includes:

- Focus timer
- Tasks
- Habits


### 🤖 Smart Coach

Free offline coach that analyzes:

- Training
- Nutrition
- Sleep
- Water
- Focus


## Technologies

Built with:

- HTML
- CSS
- JavaScript
- LocalStorage
